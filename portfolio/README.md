# Pratyush Das — Public Portfolio

This is a static, recruiter-facing portfolio. It is deliberately independent of the Higgsfield app and does not require sign-in, a backend, API keys, cookies, or a build step.

## Included

- Responsive dark navy / cyan design
- Selected work, professional experience, technical toolkit, education, certifications and contact links
- Accessible navigation and reduced-motion support
- SEO metadata and a standalone SVG spatial illustration
- No external JavaScript, fonts, images, or analytics dependencies

## Deploy on GitHub Pages

The repository includes `.github/workflows/deploy-portfolio.yml`, which publishes this folder to GitHub Pages when the portfolio files change.

One-time setup for the repository owner:
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Open **Actions** and run **Deploy public portfolio to GitHub Pages** if it has not run automatically.
4. After the workflow succeeds, the expected site URL is https://pratyush110022.github.io/GeoPilot-AI/

The GitHub Pages URL is public by default for a public repository. Visitors do not need a GitHub account to view it.
